# Wild Earth Encyclopedia

An English-language wildlife education website starter.

## Project goals
- Introduce animal species, habitats, diets, behavior, and conservation.
- Prioritize readers in the United States, with Germany as a secondary audience.
- Keep this project separate from XVIDEO2027.

## Deploy with Cloudflare Pages
1. Open Cloudflare Dashboard → Workers & Pages → Create → Pages.
2. Connect this GitHub repository: `sreynetsaret-dot/wild-earth-encyclopedia`.
3. Production branch: `main`.
4. Framework preset: None.
5. Build command: leave blank.
6. Build output directory: `/`.
7. Deploy.

## Before public launch
- Verify and expand every species fact using trusted scientific sources.
- Add properly licensed wildlife photography and record attribution where required.
- Add a real contact address and review privacy, cookies, analytics, and advertising disclosures before adding those services.
- Do not assume advertising approval or revenue; check the publisher's current requirements first.

This is an initial static-site starter, not a fully fact-checked encyclopedia.
